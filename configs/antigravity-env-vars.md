# Antigravity Environment Variables

Set these in Antigravity Settings > Environment Variables / Secret Manager.

```bash
ANTHROPIC_API_KEY=sk-...
GOOGLE_API_KEY=AIz...
GITHUB_TOKEN=ghp_...
SLACK_WEBHOOK=https://hooks.slack.com/services/...
```

Optional extras:

```bash
ANTIGRAVITY_WORKSPACE=your-workspace-id
DEFAULT_MODEL=claude-opus-5-5
```
